Preview the native interface

Build Recomp in Xcode, then open Settings → Interface preview.

The current preview uses the same SwiftUI rings, borders and readouts as the app. It contains sample data and does not save meals, connect to Health or call AI.

You can also open InterfacePreviewScreen.swift in the Xcode canvas for light, dark, empty and larger-text previews.

The earlier HTML illustration was for version 1.4 and no longer represents the current screens. No browser drawing is presented as a native screenshot.
